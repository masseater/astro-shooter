# Steam release checklist

この文書はビルド完成後にSteamworksで行う提出作業を整理したものです。Steamworksアカウント、App ID、税務・銀行情報、審査料金はリポジトリから自動設定できません。

## 現在のビルドで完了している項目

- 独自タイトル、世界観、固有名詞、物語、UIへ再設計
- Windows 64-bit、Linux x86_64、macOS universal向けGodotプリセット
- Steam SDKなしで全編プレイ、ローカル保存、設定、終了が可能
- キーボード・マウス、ゲームパッドの出撃操作
- ゲーム内クレジットと第三者ライセンス表示
- CIによるプロジェクト読込、進行テスト、リリース準備検査、配布ビルド

## Steamworks登録後に設定する項目

1. Steam Directで製品を登録し、正式な開発者・パブリッシャー名とApp IDを取得する。
2. ストア名、短い説明、詳細説明、タグ、価格、対応言語、対応OSを登録する。
3. capsule、header、library hero、ロゴ、スクリーンショット、トレーラーを各指定寸法で用意する。
4. Windows、Linux、macOSごとにDepotを作成し、本リポジトリの各buildディレクトリを割り当てる。
   `steam/*.vdf.example`をApp IDとDepot IDで複製・置換し、最初は`preview=1`でSteamPipeの差分を確認する。
5. Launch OptionをWindows `Riftweld.exe`、Linux `Riftweld.x86_64`、macOS `Riftweld.app`に設定する。
6. Steam Deck互換性テスト、複数解像度、画面スケーリング、ゲームパッド抜き差しを実機確認する。
7. 最低30分の新規プレイ、保存後の再起動、最終ボス撃破、進行リセットをDepotビルドで確認する。
8. macOS配布物をDeveloper IDで署名・notarizeし、Windows配布物をコード署名する。
9. 審査用メモに操作、セーブ場所、全編到達方法、外部アカウント不要であることを記載する。
10. Coming Soonページの公開期間とValveのBuild Reviewを完了後、リリース日を確定する。

## ストア文案

### 短い説明

未知の信号を追って封鎖宙域へ。Aether Nodeを解体し、弾幕をかいくぐり、回収したShardで船を恒久改修する短編宇宙サルベージアクション。

### 主な特徴

- 自動射撃と精密回避を組み合わせた、すぐ理解できるサルベージ戦闘
- 5つのセクターと、それぞれ異なる弾幕を展開するガーディアン
- 35件の恒久改修で、出撃のたびに火力・回収効率・機動性が成長
- 30〜45分でエンディングまで到達でき、全実績収集を狙える短編構成
- オフライン完結、外部アカウント・課金・広告なし

## 出荷判定

Steamworks固有の未完項目がすべて埋まり、公開Depotをクリーン環境にインストールして新規開始からエピローグまで完走できた時点で出荷可能と判定します。
